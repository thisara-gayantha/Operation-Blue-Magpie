# platform/nginx

Reverse proxy + TLS edge in front of CTFd (Step 4). Nginx is the **only**
service published to the host.

Planned contents (Step 4):
- `nginx.conf` — top-level config.
- `conf.d/ctfd.conf` — server block: HTTP→HTTPS redirect, TLS termination,
  `proxy_pass` to `ctfd:8000`, WebSocket upgrade headers, sane proxy headers
  (CTFd runs with `REVERSE_PROXY=true`).
- `certs/` — self-signed cert + key generated by `scripts/gen_certs.sh`
  (git-ignored; never commit private keys).
